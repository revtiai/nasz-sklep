# Nasz Sklep: storefront preview

Design preview of an online shop for Nasz Sklep, a Polish and Eastern European grocery at 120 St Mary's Road,
Southampton, selling to the public and to trade customers by the case.

- Live preview: https://revtiai.github.io/nasz-sklep/
- Brand board: https://revtiai.github.io/nasz-sklep/board.html

Products and prices are examples. The real shop is planned on Shopify, with this design as its theme direction.

```
npm install
npm run dev
```
